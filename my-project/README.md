# Character Counter

A simple Character Counter built with React and `useState`.

## 🚀 Features

- Count characters while typing
- Maximum limit of 100 characters
- Display current character count
- Clear the textarea with one click
- Responsive UI

## 🛠️ Technologies Used

- React
- JavaScript
- Tailwind CSS
- Vite

## 📂 Project Structure

src/
├── App.jsx
├── main.jsx
└── index.css

## 💡 React Concepts Practiced

- `useState`
- Controlled inputs
- `onChange`
- State updates
- Derived values using `.length`
- Conditional logic
- Event handling
